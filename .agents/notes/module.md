# GuiyuX 桌面收纳

面向 Windows 的低内存常驻桌面工具，参考 [Booki](https://github.com/punkable/booki) 的拖入固定、分组与快速打开体验。界面支持简体中文和英文。视觉方向是通过胶囊和卡片的形态变化表现展开、归类和收起。

## 收纳方式

| 方式 | 用户操作 | 版本范围 |
| --- | --- | --- |
| 灵动岛 | 平时收成屏幕顶边的胶囊。点击或用快捷键展开，选择分组，点击图标打开条目。把文件拖到岛上时显示分组投放区，松手完成收藏。 | 第一版唯一的收纳入口 |
| 卡片展开 | 多个分组封面摆在桌面上，用户按位置找到分组，点击封面原位展开，再取用其中的内容。 | 后续构想 |
| 分组卡牌 | 每个分组对应一张卡牌。用户浏览多张卡牌、选中目标组，再点击牌面上的图标打开条目。翻页、滚动等浏览手势待设计。 | 后续构想 |

三个入口共用分组、条目和排序。收藏保存应用、文件、文件夹或网址的引用；移除收藏时保留源文件。

## 当前工程

已实现 Rust + Win32 单进程工程。默认胶囊是高 18 像素的毛玻璃短条。指针悬停时，短条从中心向两侧舒展并提亮，移开后恢复。悬停底色在约 140 毫秒内渐变。指针移入分类或快捷图标时，符号左右轻晃一次，约 320 毫秒后归位。分类图标、文件行和导航按钮以较亮的底色提示键盘焦点。单击胶囊后默认显示六个快捷入口与「更多」。11 个分类共用一套无外框的单色线形符号，收起箭头在静止时使用低对比度，仅悬停、按下或键盘聚焦时提亮。设置页的分类入口复用这套图形，固定的文件和应用优先显示系统图标。胶囊从顶边中央舒展，图形渐显。分类栏右端的上箭头将整栏收回，点击岛外也会自动收起。分类栏只显示图标，悬停时在控件下方显示深色圆角提示。详情左侧的同款左箭头用于返回，文件列表从顶端开始。关闭系统界面动画时，图标保持静止，悬停和收展直接切换到目标状态。点击分类查看自动归类的条目，每页显示五项，以文件名和父目录区分同名条目。投放后在胶囊内短暂显示结果。右键菜单的「设置…」打开石墨灰设置窗口，左侧可切换收纳、快捷栏、整理规则、外观和界面语言。「界面语言」位于设置中，支持整行点选和方向键切换，选择即时保存。跟随系统一行显示实际采用的语言。右键菜单使用 14 像素文字和 16 像素图标，悬浮提示使用 12 像素文字。菜单外沿半径为 8 像素，各菜单项共用 4 像素圆角的悬停底色。选择红色的「退出」直接结束程序。配置与收藏保存在本地 JSON 中。同一配置目录使用实例锁，写入时原子替换文件。构建入口、运行方式和源码职责见[工程说明](../../README.md)。

当前渲染使用 Win32 控件和 GDI 离屏绘制。图标、悬停底板与导航箭头在六倍采样画布中合成后取平均。胶囊、悬浮提示和右键菜单按像素覆盖率合成透明圆角。菜单的外沿与内缩高亮使用同心圆弧。自绘菜单弹出时临时关闭原生矩形投影，避免浅色背景从圆角与投影之间露出。菜单显示后立即恢复原有类样式。Win32 继续处理菜单的选取、键盘和辅助功能。窗口尺寸与画面同时提交。Direct2D / DirectWrite 是后续定制视觉方案。收纳文件夹与快捷入口已接入灵动岛。卡片视图和性能预算仍待实现或验证。

## 灵动岛与菜单外观

「设置 → 外观」中的背景效果和透明度由灵动岛与右键菜单共用，沿用已有配置，默认使用 30% 毛玻璃。滑杆支持实时预览和方向键微调，右侧输入框可直接填写 0 到 100 的任意整数。外观页和整理规则页的下拉列表使用石墨灰底、圆角高亮和当前选项勾选标记，沿用 Windows 的键盘选取行为。

收起的胶囊、快捷栏、「更多」网格和分类详情都随外观设置即时更新。Windows 合成器柔化岛后桌面，岛面叠加冷灰渐变和细边缘高光。分类名、计数和文件名在独立前景层按屏幕像素绘制，高透明度时加细暗边以保持浅色桌面上的可读性。透明模式直接透出背景，0% 恢复实色。系统无法提供背景模糊时退回透明，高对比度模式下岛面使用实色。

普通菜单、图标菜单及子菜单每次打开时读取 Windows 应用主题，浅色用雾白底和深灰字，深色用石墨灰底和浅色字。菜单采用细描边、分隔线和内缩的圆角悬停高亮。毛玻璃取样弹出位置的局部背景，菜单以所选透明度的一半透出背景，让文字在明暗桌面上都容易辨认。透明模式直接使用所选透明度。系统高对比度模式使用原生菜单。视觉参考见 [Booki 的 Dock 菜单](https://github.com/punkable/booki/blob/d4eaff03f30e422e26f792d9e366e1f03e4c5054/src/styles/menus.css)。

## 首版设计建议

优先跑通拖入、分组、打开、收起和重启恢复。其他候选功能包括搜索、托盘入口、全屏避让、显示器选择、按屏幕缩放以及失效路径修复。界面文字随系统语言初始化，并支持手动切换；用户命名的分组保留原文。

## 收藏分类与自动整理

按用途识别应用，按内容识别文件。整理范围是用户已收藏的引用，每项只进一个分类。打开条目时仍使用原收藏路径，保留快捷方式的启动参数。

| 默认分类 | 内置规则与典型条目 |
| --- | --- |
| 办公通讯 | 微信、企业微信、飞书、Teams、Outlook、WPS 等沟通与办公应用。 |
| AI 助手 | ChatGPT、Claude、DeepSeek、豆包等通用助手。专用工具按主要用途归类。 |
| 开发工具 | VS Code、Visual Studio、Git、Cursor、Claude Code 等开发工具，以及 .rs、.py、.code-workspace 等源码或工程文件。 |
| 设计创作 | Photoshop、Figma、Midjourney 等创作工具，以及 .psd、.ai、.fig 等设计源文件。 |
| 实用工具 | 已识别的通用工具，如浏览器、7-Zip、PowerToys。 |
| 文档 | 沿用现有文档格式，包括 .docx、.xlsx、.pdf、.md 等。 |
| 图片 | 沿用现有图片格式，包括 .png、.jpg、.svg 等。 |
| 影音 | 现有音视频格式和已识别的播放器，如 .mp4、.flac 和 VLC。 |
| 压缩包 | .zip、.7z、.rar、.tar.gz 等归档文件。 |
| 文件夹 | 普通目录，以及目标为目录的快捷方式。 |
| 其他 | 收纳剩余条目，包括缺少识别信息的程序、目标失效的快捷方式和未知格式。 |

**规则怎样匹配**

1. 手动指定的分类优先。条目右键可选「移至分类或文件夹」，以后整理时保留该选择。选「跟随规则」可解除手动指定，自动整理开启时会立即重新判断，关闭时留待下次整理。
2. 再查用户规则。「设置 → 整理规则」每条规则选一个条件（应用标识、完整文件名或扩展名）和一个目标分类。名称和扩展名忽略大小写，多条命中时取列表中靠前的一条。例如给 .drawio 建一条「设计创作」规则，即可同时覆盖已有和新收藏。
3. 最后查内置规则。对 .lnk 读取目标，按目标的应用标识、目录类型或文件格式分类。程序依次匹配应用 ID、产品名和已知程序名。文档名中出现应用名称不会触发应用规则。例如「开会.lnk」指向 Teams 时进「办公通讯」，「微信会议纪要.docx」进「文档」。网页快捷方式（.url）按目标网址的域名匹配。ChatGPT 桌面版通过应用标识识别，指向 `chatgpt.com` 的网页快捷方式通过域名识别，两者都进「AI 助手」。仅有「ChatGPT」的名称、目标无法识别且没有其他规则命中时，归入「其他」。其余未命中项也归入「其他」。

**自动整理开关**

「设置 → 收纳 → 自动整理新收藏」默认开启，开关状态和收藏位置在重启后恢复。拖到胶囊、没有指定落点时，开启就按规则归类，关闭就收入「其他」并提示「已收纳到其他」。切换开关时已有图标留在原处。两种状态下，收起灵动岛都会把快捷栏和组内图标一起收起，展开后可照常取用。收藏保存引用，源文件和桌面图标保留原位。

旧版只保存路径的收藏在升级后首次载入时按默认规则归类。重新开启自动整理后，从下一次投放开始匹配。要处理此前积累的收藏，可随时从胶囊右键选择「立即整理」，包括开关关闭时。该操作保留手动归属、快捷栏位置和手动排序，完成后显示调整数和「其他」总数，并提供「查看其他」。连续执行两次且规则和收藏都相同时，第二次调整 0 项。编辑规则可预览受影响条目的原分类与新分类，选择「保存规则」供下次使用，或选「保存并整理」立即执行一次。

**快捷文件夹与图标放置**

在「设置 → 快捷栏」可新建、命名和调整收纳文件夹的显示顺序，也可选择一个本地目录作为快捷入口，日后可在此更换目录。点击自建文件夹查看其中的收藏，点击本地目录入口则在资源管理器中打开。移除快捷入口保留原收藏；删除自建文件夹时，其中的收藏统一收回「其他」。

把桌面图标拖到胶囊上方可展开投放区，岛内已有图标也可直接拖动。松手前显示目标高亮或插入线，两种落点各有明确动作。

| 落点 | 松手后的结果 |
| --- | --- |
| 高亮的分类或自建文件夹 | 图标归入该组，记录为手动指定。开关关闭时同样可以放入，再次整理时保留归属。 |
| 快捷栏上的插入线 | 在该位置固定可单击打开的独立图标。固定只增加入口，同一收藏仍只有一个归属。 |
| 组内两个图标之间 | 将图标放到插入线位置并记住顺序。跨组拖入时同时更新手动归属。组内未手动调整前沿用最近收藏在前的顺序。 |

快捷栏默认显示办公通讯、开发工具、文档、文件夹、AI 助手和设计创作六个入口，另设「更多」和收起按钮。首次升级时沿用旧版默认顺序并补齐两项，自定义快捷栏保留原样。用户可拖动快捷文件夹或独立图标调整位置，超出首屏的入口在「更多」中可达。点「更多」时首排保持原位，同一窗口增宽并向下展开三列网格，显示其余分类、收藏数及溢出的快捷入口。每页最多十二项，翻页只切换网格。再次点「折叠更多」或按 Esc 回到单行，右侧上箭头收起整个灵动岛。「其他」在网格末尾，已固定到首排时从首排打开。条目右键提供「移至分类或文件夹」和「固定到快捷栏」，也可以用菜单完成放置。

## 技术路线与验证

已选定 Rust + Win32。建议以一个原生窗口承载胶囊和展开面板，Win32 处理窗口消息、热键和拖放，Direct2D 绘制形状和图标，DirectWrite 排版中英文。建议仅在状态变化或过渡动画期间重绘，图标按需加载并限制缓存容量。自绘界面需要专门验证键盘焦点、中文输入、读屏和透明区域的鼠标命中。

首轮原型建议在 Windows 11 x64 上放入 100 个收藏，记录收起五分钟后的专用工作集、专用提交量和空闲 CPU 时间，再测连续开合 100 次后的变化。同机以相同条目对照 Booki，计入其相关子进程。40 MiB 是收起时专用工作集的探索预算，实际占用和相对节省量待测。
